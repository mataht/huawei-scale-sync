# Huawei Scale Sync — public information pages

This repository contains only the public homepage, privacy policy and terms for Huawei Scale Sync, a personally hosted scale-to-Google-Health synchronization tool.

It is a static informational website. It has no registration, login, health-data forms, analytics scripts or backend. It contains no measurements, device identifiers, account identifiers, OAuth credentials or private deployment configuration.

## Files

- `index.html` — application homepage
- `privacy.html` — privacy policy
- `terms.html` — terms and usage information
- `.nojekyll` — serve these files directly with GitHub Pages
- `.gitignore` — allow only the reviewed public file list

The application itself runs in its owner's local environment. This repository does not contain the bridge software or grant access to the owner's devices or accounts.

Huawei Scale Sync is not an official Huawei or Google application.
